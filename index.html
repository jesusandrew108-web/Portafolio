Punto de venta con panel web de precios

Las tiendas dependían de que cada encargado actualizara los precios. Construí un punto de venta conectado a un panel web, para que la oficina cambie productos y precios de todas las sucursales desde un solo lugar.

  • Catálogo sincronizado con cada punto de venta.
  • Cobro rápido con lector de código de barras y atajos de teclado.
  • Cortes de caja por sucursal, con filtro por fechas y desglose.

  • MySQL

Punto de venta para tienda de abarrotes

Sistema de escritorio para operar una tienda de abarrotes en el día a día: vender, controlar el inventario y cerrar la caja con el efectivo contado.

  • Venta por búsqueda, categorías o lector de código de barras, con pago en efectivo, tarjeta o transferencia.
  • Inventario con existencias y aviso de stock bajo.
  • Corte de caja con conteo de billetes y monedas, comparado contra lo vendido, e historial de cortes con aprobación.
  • TypeScript
  • JavaScript
  • HTML
  • CSS

Punto de venta con alerta de emergencia

Punto de venta sencillo para una tienda con riesgo de asaltos. Un comando de emergencia, escrito en el campo del escáner, envía una alerta al grupo de encargados y dueños con la sucursal, la fecha, la hora, el día y un mensaje de auxilio.

  • Alerta inmediata por mensaje al grupo.
  • Venta con catálogo por categorías, escáner de código de barras e impresión de ticket.
  • Inventario con alta y edición de productos.
  • Corte de caja que no permite superar las ventas del día, con aprobación de cortes.
  • TypeScript
  • JavaScript

  • CSS
